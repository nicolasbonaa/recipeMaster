O RecipeMaster é uma plataforma onde os usuários podem visualizar, favoritar e compartilhar
receitas culinárias, além de buscar receitas com base em ingredientes disponíveis.

Funcionalidades para Usuários:

Cadastro e autenticação.
Exploração de receitas organizadas por categorias.
Favoritar receitas e criar listas personalizadas.
Upload de novas receitas com imagens.
Avaliação e comentários em receitas.
Seguir / deixar de seguir outros usuários (cozinheiros).
Curtir / descurtir receitas.
Feed "Seguindo" (receitas de quem você segue) e Feed "Geral" (todas as receitas).

Funcionalidades para Administradores:
Dashboard administrativo.
Cadastro e gerenciamento de receitas e categorias.
Moderação de conteúdos e usuários.
